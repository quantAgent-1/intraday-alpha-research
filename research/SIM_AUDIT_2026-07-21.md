# Simulator Stream-Contamination Audit — enginev5.1

**Date:** 2026-07-21
**Question audited:** "If the simulator is vectorized, couldn't it risk mixing up the stream of data signals, making it different from an actual realtime stream?" — i.e., can any value at index `i` depend on information a live stream would not yet have had at that instant?
**Scope:** `backtest/{replay,fills,latency,tape,auction_replay,decompose,stress}.py`, `events/` (context, event_bars, entry_quality, all 5 detectors), `plans/` (constructor, overlay_a1, overlay_m4), `features/` + `labels/`, `models/m8v2_features.py` + A1/M4 pred producers, `data/` (store, backfill, alpaca_hist, noii, bbo1s, calendar), `flows/letf.py`, `apps/{run_trial,run_moc_trial,backfill}.py`, tests. Empirical checks run against the live lakes and shipped pred parquets.
**Method:** line-level read of every file above; every claim verified against source or measured against on-disk data (bar-vs-tape ratio scans, partition mtimes, pred-row timestamp phase). Docstrings treated as claims, not evidence.

---

## 1. Executive summary

**The vectorized walk-forward machinery itself is largely sound.** Detector loops read only `[0..i]`, polars windows are session-fenced, the fill kernel's `searchsorted` conventions are correct and pinned by tests. The real contamination is at the **seams between arrays from different sources** — three confirmed cases where a consumed value could not have existed in a real-time stream at that instant:

| # | Finding | Class | Status | Blast radius |
|---|---------|-------|--------|--------------|
| F1 | Detector price anchors computed on **dividend-adjusted bars**, executed against the **raw tick tape** (−1.5 to −83 bps measured offset, itself a function of *future* ex-dates) | join/alignment + restatement | **CONFIRMED, measured** | M3/A0 payer economics (vwap_magnet ALIVE +6.2), all bar-anchored payers, NVDA/MU/GOOGL only. NOT the champion — `moc_imbalance_v1` is clean (§2 Materiality) |
| F2 | A1/M4 pred rows stamped at **bar open** but containing that bar's **close**; consumed at `ts <= decision_ts` → 60 s look-ahead on 5-min-mark decisions | look-ahead + alignment | **CONFIRMED, verified on shipped parquets** | Overlay arms only; all ledgered overlay verdicts were negative ⇒ a-fortiori safe |
| F3 | N-PORT AUM joined on **period-end date**; the **filing date (~60 d later) sits unused in the same CSV row**; AUMs move 3–10× inside the lag | publication lag | **CONFIRMED** (self-flagged in M12 report; now quantified) | M12 Cell A ledger evidence; M8-v2 (killed) |
| F4 | Pre-admission staleness void consumes the *future* latency draw before slot reservation | path-dependent state | CONFIRMED, **latent** (dead code for current plans) | none today; live if plans ever author near curfew / short validity |
| F5 | Stop-trigger transition semantics; unbounded quote staleness in `market_fill`; anachronistic static LETF AUM toml (provably inert) | fidelity notes | PLAUSIBLE / minor | second-order |

**Single highest-value follow-up:** refetch bars1m for the 5 signal symbols with `adjustment="raw"` (pattern already in-repo: `run_xs_reversal.py:172`, `run_m11.py:257`) and re-run `M3-A0-v1.1-4sym`. The ledger's per-symbol edge split matches F1's predicted pattern exactly (edge only on offset symbols), so this re-run either clears or retracts the vwap_magnet ALIVE claim. (Terminology: "champion" in this project = `moc_imbalance_v1`, which F1 does not touch.)

## 2. F1 — CONFIRMED: adjusted-bar anchors vs raw fill tape

### Code path

- `src/enginev51/data/alpaca_hist.py:133` — `fetch_bars_multi(..., adjustment="all")` default.
- Legacy `engineV5/src/enginev5/apps/backfill.py:82` used the default → the **entire legacy bars1m lake is split+dividend back-adjusted**. New-lake `data/backfill.py:291` (`run_letf_bars`) same. Primary lake bars1m holds only SOXL/SOXS/TQQQ/SQQQ ⇒ **all signal-symbol bars come from the adjusted legacy lake**.
- `events/context.py:139-143` loads these bars; detectors derive **absolute price anchors** from them:
  - `vwap_magnet.py:119-127` — `stop_px` anchored at `close[i]`, `t0_px = cum_vwap`
  - `gap_mr.py:79-90` — `p945`, `t1_px = prev_close`, stop from window hi/lo
  - `cascade.py:210-220` — `extreme_px` from bar high/low
  - `expiry_pin.py:79-98` — **strike grid rounded on the adjusted price**; 5–30 bps distance gate
  - `letf_window.py:71-74` — stop anchored at adjusted `p1500`
- `plans/constructor.py:108-114` prices the **entry limit from the raw tape** (`ctx.quote_at` → event bars → raw quotes); `backtest/replay.py`/`fills.py` execute all legs against raw prints/quotes (`tape.py` applies no adjustment).

So a plan mixes two price scales: entry leg on the raw scale, stop/target legs on the adjusted scale.

### Empirical measurements (this audit, 2026-07-21)

Median of per-minute bar-VWAP ÷ tape-VWAP over 390 RTH minutes; IQR < 0.5 bps throughout. AMD/TSLA (no dividends) are zero-controls proving the method's noise floor is ±0.03 bps.

| symbol | 2025-10-15 | 2026-02-17 | 2026-05-15 |
|--------|-----------|-----------|-----------|
| NVDA | **−12.74 bps** | **−12.16** | **−11.64** |
| GOOGL | **−19.52** | **−13.01** | **−5.98** |
| MU | **−9.76** | **−5.75** | **−1.51** |
| AMD | +0.02 | +0.01 | +0.03 |
| TSLA | +0.01 | +0.00 | +0.00 |

- MU 2024-02-05 (the `M3-A0-ext2024-MU` window, 361 sessions): **−82.9 bps**.
- Partition mtimes: the whole MU (and sibling) bar history was bulk-fetched **2026-07-13**, so a session's offset is the cumulative factor of every ex-date between that session and 2026-07-13 — **dividends declared after the session determine its bar prices** (the class-4 angle).
- NVDA's constant ≈ −12 bps across the whole trial window is consistent with one large ex-date between 2026-05-15 and the fetch date; whatever its corporate-action origin, the AMD/TSLA controls validate the measurement.

### Wrong output produced

For a long vwap_magnet plan on NVDA: enter at the raw bid; profit target sits at `raw_vwap × (1 − 12 bps)` (easier, smaller wins); stop ~12 bps deeper than registered. Shorts mirrored opposite (harder targets, tighter stops). `constructor.py:126-127`'s side-sanity veto then asymmetrically deletes near-VWAP longs (a long needs raw_bid < adjusted vwap, i.e. dev must already exceed the offset just to author). `expiry_pin`'s strike choice and distance gate shift by ~40% of the gate width on NVDA.

### Materiality

- Payer-family claim `vwap_magnet` ALIVE **+6.20 [2.60, 9.99]** (M3-A0-v1.1, NVDA+TSLA 2025-09-02..2026-05-31): half the book (NVDA) carried a constant −12 bps anchor displacement **larger than the claimed edge**.
- Ledger per-symbol split (M3-A0-v1.1-4sym) matches the defect's predicted pattern exactly: **NVDA +11.23, MU +9.01 (offset symbols) vs TSLA +0.61, AMD −0.40 (clean controls)**. Circumstantial — the net sign of the distortion is analytically ambiguous (longs and shorts distort oppositely) — but cheap to falsify with the raw-bars re-run.
- **Untouched by F1:** MOC/auction family (raw `bars1d` + raw tape + NOII), all event-bar paths, every ratio-form quantity (`dev`, `sigma_d_bps`, z-features, `expected_gross` hurdles), daily-bar experiments (fetched `adjustment="raw"` deliberately).
- Secondary, currently latent: partitions fetched at different vintages embed different cumulative factors ⇒ any future incremental month fetch after a new ex-date creates a phantom ~1-ex-date step in `prev_close`/gap/`sigma_d` across that month boundary (`context.py:146-221` spans up to 2 partitions). Today moot (whole lake one vintage).

### Fix

Refetch bars1m for signal symbols with `adjustment="raw"` into the primary lake (primary-first shadowing already works, `store.py:103-121`); or compute anchors on ratios only and re-express levels off the raw event-bar quote at decision time. Then re-run M3-A0-v1.1 / -4sym / ext trials and compare.

## 3. F2 — CONFIRMED: one-bar look-ahead in A1/M4 prediction lookup

### Code path

- `features/grid.py:41` — feature-grid rows stamped at **bar open** (`ts = open_ns + i*NS_PER_MIN`).
- `features/slow.py:65-74` — the row's features use the row's own bar **close** (knowable only at `ts + 60 s`).
- `apps/train_a1.py` emits pred rows on those stamps; **shipped parquets verified: 100% of `data/preds/a1_v1/*.parquet` rows sit on 5-minute wall-clock marks** (10:00:00 … 15:30:00, incl. 13:00:00 and 15:00:00).
- `plans/overlay_a1.py:111` and `plans/overlay_m4.py:122` — `row_at` selects the last row with `pl.col("ts") <= ts` (decision instant).
- Detector decision instants are minute marks (`ts[i] + 60 s`). Whenever a decision lands on a 5-minute mark it **selects the pred row stamped at that exact instant**, whose features include 60 s of future tape relative to `ts_authored` (and ~35–55 s beyond the modeled entry action).

**Affected decisions under `--arm a1|m4`:** expiry_pin — all (13:00–14:30 on 5-min steps); letf_window — all (15:00:00); vwap_magnet / cascade — ~1 in 5 minutes. gap_mr (09:45) unaffected (no pred row before 10:00 ⇒ `pred is None` ⇒ plan unchanged).

**M4 encoder nuance:** its fine/sess input streams end strictly before ts (`models/encoder/dataset.py:557-562`, `e = offset − 1`) — clean — but the **static block** re-imports the leak via `searchsorted(feat_ts, ts, side="right") − 1` at `dataset.py:655` on 5-minute-mark anchors. M4 pred rows exist at every minute (verified on `data/preds/m4_v1/NVDA.parquet`), so every M4-overlay decision picks the row at its own instant; the leak enters through the static f_* dims on the 5-min-mark subset.

### Wrong output produced

The rule-1 veto (`overlay_a1.py:151`) filters the traded plan population using the next minute's move; MFE/MAE leg re-pricing likewise. This is a future-information filter on which plans exist in the overlay arms.

### Materiality

Bounded and in the safe direction for existing verdicts: the a0 arm never touches preds, and **every ledgered A1/M4 verdict was negative despite a leak that favored the overlays** — those kills are a-fortiori sound. The defect blocks any *future* positive overlay claim until fixed.

### Test-pinning gap

`tests/test_overlay_a1.py:286` (`test_provider_row_at_pit_last_le_ts`) **pins the defective convention as correct**. `tests/test_features.py:122` pins producer truncation-invariance only. Nothing anywhere pins the producer-stamp ↔ consumer-availability contract — exactly where this defect lives.

### Fix

Either consume with `pred.ts <= decision_ts − 60 s` (the exact analogue of `context.quote_at`'s completed-bucket rule, `context.py:94-113`), or stamp pred rows at bar close at emission. Add a test that a pred row's ts is its availability instant.

## 4. F3 — CONFIRMED (self-flagged, now quantified): N-PORT AUM period-date join

### Code path

- `models/m8v2_features.py:222-263` (`_asof_attach_sum`): `join_asof(..., strategy="backward", allow_exact_matches=False)` on `adate = asof_date`.
- `scripts/m12_cell_a.py:76-93`: identical convention (the m8v2 module ports it verbatim, per its own docstring).
- `data/external/letf_aum_anchors.csv`: `asof_date` is the **N-PORT reporting-period end**; the **filing date is present but unused** inside the `note` field. Measured examples (Direxion files at the ~60-day statutory limit):
  - AMDD 2025-04-30 → `filed=2025-06-27` (58 d)
  - AMDD 2025-07-31 → `filed=2025-09-29` (60 d)
  - AMDD 2025-10-31 → `filed=2025-12-29` (59 d)
- Same rows show AUM moving **3–10× between anchors** ($2.5M → $8.8M → $24.2M), so the not-yet-public value is very different from the last public one — this is not a small restatement.

### Wrong output produced

For ~2 months after each period end, `F(t)`, `abs_f_over_adv`, and `complex_intensity` use an AUM the market could not have known. The M12 Cell A "mechanism PASS / MU predicted ex-ante" alignment evidence was computed under this convention.

### Materiality

- **M8-v2** was the only *gated* consumer and is KILLED (2026-07-20) — no live economics rest on it.
- **M12 Cell A** remains ledger evidence for the champion mechanism narrative. Its report carries one flag line ("F(t−1) uses N-PORT-anchored AUM with real-world publication lag; a deploy version would…"); the quantification above is stronger than the flag suggests.

### Fix

One-line data change: parse `filed=` from `note` into a `public_date` column and as-of join on that. Re-run `m12_cell_a.py` alignment stats; the mechanism claim either survives on public-information anchors or it doesn't.

## 5. F4 — CONFIRMED, latent: staleness void skips slot reservation using the future latency draw

`backtest/replay.py:156-158`: `entry_action > plan.valid_until or entry_action >= plan.curfew_ts` voids **before** the v1.2 reserve-at-authored slot logic (lines 161-164) and records no occupancy. The realized latency draw — future information at `ts_authored` — decides that attention was never committed; a concurrent plan then sees a free slot a real-time human would have occupied. Same hole class the 2026-07-16 audit (#1/#2) closed, one branch earlier.

**Currently dead code for the A0 population:** `VALID_FOR_S = 120 s` (`constructor.py:58`) > max latency 25 s, and all authoring windows end ≥ 40 min before curfew. Becomes live the day any runner authors plans with shorter validity or near curfew. Fix while it is still free: reserve the slot at `ts_authored` first, then void with occupancy `[authored, entry_action)`, mirroring the v1.5 post-admission paths.

## 6. F5 — Plausible risks / fidelity notes (not proven material)

1. `fills.py:181-205` `stop_trigger_ts` opens **strictly after** `max(cursor, stop_arm)`: a book already through the stop at the arm instant triggers only on the *next* quote update (transition, not level, semantics). Can only delay modeled stops; sub-second on these names.
2. `fills.py:158-178` `market_fill` has no staleness bound on the prevailing quote; `tape.py:59` drops crossed/locked quotes, so a market-out in a broken-book moment can fill at an arbitrarily old quote. A hold-expiry after the final quote fills at the session's last pre-expiry quote.
3. `flows/letf.py:113-141` `complex_demand` uses a static current-AUM toml for all historical sessions (anachronism) — **provably inert** for `letf_window`: `L² − L > 0` for every fund, so `sign(demand) = sign(r)` regardless of AUM, and only the sign plus r-derived magnitudes are consumed.

## 7. Checked and clean (verified, not assumed)

- **`backtest/fills.py`** — windows `(after, to]` via `searchsorted(side="right")`; placement-instant prints never fill; every `prevailing_idx` call site guards the −1 wrap; v1.3 quote-confirmation reads the quote at-or-before the print. Pinned by `tests/test_fills.py`.
- **`backtest/replay.py` (post-admission)** — reserve-at-authored slots causally exact for the current population; deterministic tie-break `(ts_authored, −EV, plan_id)`; stop-vs-target ties to the stop; v1.5 failure paths keep occupancy; latency deterministic per (seed, plan_id, leg) via sha256. Pinned by `tests/test_replay.py` (incl. `test_post_admission_void_keeps_slot_occupied`, `test_deterministic`).
- **Detectors (all 5)** — decisions stamped `ts[i] + 60 s` (UTC arithmetic, DST-proof); read `[0..i]` only; σ windows end at `i+1` slice-exclusive; re-arm/episode dicts iterate in ascending time exactly as a stream would; cascade's event-bar masks (`eb_ts < decision_ts`) admit only fully-closed 1 s buckets on second-aligned decisions.
- **`events/event_bars.py`** — tick-rule, OFI, trade classification all previous-only; aggregation within-bucket; counts zero-filled, state left null (no back-fill).
- **`events/context.py`** — trailing stats sealed by end-bound load at session open (pinned by `test_context.py::test_pit_no_future_leak`); `quote_at` enforces the completed-bucket rule.
- **`events/entry_quality.py`** — same completed-bucket rule; rolling sums over completed seconds only.
- **`features/slow.py` + `labels/forward.py`** — session-fenced shifts; masked global rollings cannot span sessions; daily aggregates `shift(1)`-ed; descending-sort forward-extrema guarded by the `_rows_after >= h` mask (the cross-session `shift(1)` bleed only touches rows that are nulled). Today's full-day `sess_ret` is joined onto intraday rows at `slow.py:169` but never reaches the training matrix (`materialize.py:85` selects META/FEATURE/LABEL cols only) and is otherwise consumed only `shift(1)`-ed.
- **A1 fold discipline** — expanding walk-forward, 1-session embargo, `trained_through < session` asserted per emitted row (`train_a1.py:209`); holdout stripped and re-asserted.
- **MOC/auction family** — `signal_at` last-message-at-or-before 15:50:10; persistence flip read at 15:55:00 pre-latency (`run_moc_trial.py:238-243`); `adv20_dollars` strictly prior sessions; cross price from conditioned prints or raw `bars1d`; entries on raw quote tapes. **This family avoids F1 entirely.**
- **`m8v2_features.py` intraday windows** — `[09:30, 15:55:10]` bounds, backward-only `prevailing_mid`, append-after-decision invariance unit-tested (`test_m8v2_features.py:142`). (Its AUM join is F3.)
- **`decompose.py`** — pure fill arithmetic with algebraic identity residual. **`stress.py`** — frame transforms + seeded clustered bootstrap. **`tape.py`** `widen_tape` elementwise. **`calendar.py`** — pandas_market_calendars handles half-days/DST; half-day no-15:00-bar stand-downs correct.
